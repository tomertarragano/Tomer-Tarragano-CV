# CV website

A web version of the CV for job applications. Same navy/serif design as the printable CV, laid out as a page rather than an A4 sheet.

## Open locally

Double-click `index.html`, or from this folder:

```powershell
python -m http.server 8080
```

Then open http://localhost:8080

## Share with an application

The whole site is the `website/` folder (`index.html`, `styles.css`, `Tomer-Tarragano-CV.pdf`). Host that folder on GitHub Pages, Netlify Drop, or any static host, then paste the URL into the application.

## Files

- `index.html` — page content
- `styles.css` — layout and colours
- `Tomer-Tarragano-CV.pdf` — downloadable CV
